# 우리 학교 오늘 (v2)

내 위치(GPS·와이파이) 또는 접속 IP로 가까운 학교를 찾아, 그 학교의 오늘·내일 급식과 날씨·미세먼지·기상특보를 한 화면에 보여 주는 사이트입니다. 전국 초·중·고 12,004곳을 지원합니다.

## 폴더 구성
- `public/index.html` — 화면 (학교 고르기 + 오늘의 학교)
- `public/warnings.html` — 기상특보 확인용 페이지 (원본과 해석 결과 보기)
- `netlify/functions/schools.mjs` — 학교 찾기 (위치·IP·이름 검색·ID)
- `netlify/functions/meal.mjs` — 급식 (나이스)
- `netlify/functions/weather.mjs` — 날씨(기상청) + 미세먼지(에어코리아) + 특보 반영 + 운동장 신호등 판단
- `netlify/functions/warnings.mjs` — 기상특보 (화면이 20분마다 따로 확인)
- `netlify/lib/warnings-core.mjs` — 특보 해석·학교 지역 매칭 (반영할 특보 목록은 이 파일 맨 위)
- `data/schools.csv` — 전국초중등학교위치표준데이터 (공공데이터포털 원본 CSV)
- `tools/build-schools.mjs` — 배포할 때 CSV를 `generated/schools.json`으로 자동 변환
- `netlify.toml` — Netlify 빌드 설정

## Netlify 환경변수
- `NEIS_API_KEY` — 나이스 교육정보 개방 포털 인증키
- `DATA_GO_KR_KEY` — 공공데이터포털 일반 인증키(Decoding). 아래 4개 서비스 활용신청 필요
  - 기상청_단기예보 ((구)_동네예보) 조회서비스
  - 한국환경공단_에어코리아_대기오염정보
  - 한국환경공단_에어코리아_측정소정보
  - 기상청_기상특보 조회서비스

환경변수를 바꾼 뒤에는 **Deploys → Trigger deploy** 로 다시 배포해야 적용됩니다.

## 화면 구성
- **날씨 칸 (순수 날씨)**: 지금 기온·습도, 오늘 최저/최고, 지금 시각 강수확률, 지금 비/눈, 미세먼지·초미세먼지, 내일(하루 전체) 날씨
- **운동장 신호등 (학교 생활 기준, 등하교 7:30~16:30)**
  - 0:00~16:29 오늘 기준 / 16:30~24:00 **내일 기준** ("내일 ⚠️ …")
  - ❌ 실내 권장: 미세먼지 '나쁨' 이상, 지금 비/눈, 최고 33℃ 이상, 경보
  - ⚠️ 주의: 등하교 시간 비 예보, 강수확률 60% 이상, 새벽 비, 31~32℃, -5℃ 이하, 강풍 9m/s 이상, 주의보
  - 내일 기준일 때 지금 발효 중인 경보는 ⚠️ 로 한 단계 낮춤
- **기상특보**: 강풍·호우·대설·태풍·폭염·한파·황사만 반영 (풍랑·건조·폭풍해일 제외). 경보·태풍은 빨간 띠로 강조
- **급식**: 오늘·내일, ‹ › 로 급식 있는 날만 넘겨 보기, 1분 동안 안 만지면 오늘로 복귀
- **화면 크기**: 내용이 길면 자동으로 줄여 한 화면에 맞춤(최소 80%). 높이 520px 이하 가로 화면(800×480 등)은 3단 배치

## 갱신 주기
| 상황 | 동작 |
|---|---|
| 접속·브라우저 새로고침·'새로고침' 버튼 | 급식·날씨·특보 모두 바로 불러옴 |
| 켜 둔 화면, 낮 6~18시 | 날씨 매시 20분 · 특보 20분마다 · 급식 3시간마다 |
| 16:30 | 신호등을 내일 기준으로 전환 (다시 불러오지 않음) |
| 켜 둔 화면, 밤 18~6시 | 쉼 |
| 자정 0:01 | 급식·날씨 새로 불러와 날짜를 넘김 |
| 꺼졌던 화면이 다시 켜질 때 | 오래된 것만 바로 다시 불러옴 (날씨 1시간·급식 3시간·특보 20분 기준) |

서버 캐시: 급식 30분, 날씨는 다음 '매시 15분'까지, 특보 10분, 학교 목록 하루.

## 학교별 바로가기 주소
- 학교를 고르면 주소가 `…/?s=학교ID` 로 바뀝니다. 이 주소를 즐겨찾기하거나 QR로 만들면 그 학교가 바로 열립니다.
- 터치가 안 되는 화면(라즈베리파이 + HDMI 모니터 등)은 `…/?s=학교ID&nav=0` 으로 열면 넘기기 버튼이 숨겨집니다.

## 학교 자료 새로 고치기
1. 공공데이터포털에서 「전국초중등학교위치표준데이터」 CSV를 새로 내려받습니다.
2. GitHub의 `data/schools.csv`를 새 파일로 바꿔 올립니다 (파일 이름은 `schools.csv` 그대로).
3. Netlify가 자동으로 다시 배포하면서 변환합니다. 화면 맨 아래 '데이터기준일'이 바뀌면 완료.
